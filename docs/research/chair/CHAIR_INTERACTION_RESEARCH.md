# 机器人—椅子交互运动研究

调研日期：2026-09-22。分支：`codex/robot-chair-interaction`。对应 P4-T03，接口延伸至 P4-T01/T04。状态：**PARTIAL，代码与方案已编写，未运行测试、demo 或训练**。

工程入口：[接口与运行说明](CHAIR_INTERACTION_ENGINEERING.md)。本轮不改变既有 Dex5 受支撑打字工作的验证结论，也不把支撑机构提供的稳定性计为自由坐姿能力。

## 1. 研究目标

机器人已经坐在无动力脚轮椅上，通过间歇足—地接触移动机器人与椅子，接收躯干坐标系下的平面速度指令。一次技能结束后，独立观测必须证明：机器人和椅子都有正确方向的进度、保持坐姿接触、停止并重新进入屏幕可见且双手可达的工作姿态。

本分支先研究“坐稳 → 移动 → 停止 → 工作姿态交接”。走到椅子、自由坐下、站起和打字仍由原 P4/P2 技能负责。把这些阶段分别验证，才能定位失败来自椅子动力学、策略、传感器还是任务交接。

### 最直接基线带来的工程选择

Stay Seated 的球形脚轮近似，与本仓库已有转向轴和滚动轴的脚轮不同；应把这种差异列为模型消融。其 FS-only 出现静止局部最优的现象，提示我们把“有正确方向的运动”作为独立验收项。论文 actor 不使用接触输入，并不意味着本项目的独立安全层也不需要接触估计。这里的训练、验证和安全是三个独立接口。[原文 §III–V](https://arxiv.org/html/2608.28090v1)

## 4. 待检验的研究问题

### H1：正确方向的机器人—椅子共同进度，比只看存活和路径长度更可靠

对照：只看 episode 存活/速度积分，与同时检查机器人和椅子的有符号位移。注入原地摆动、反向运动、骨盆在静止椅面上挪动、观测冻结。预期：严格验证器拒绝伪进度。如果它也显著拒绝正常的座面转动，应重新定义座面与椅架测量坐标，而不是放宽所有位移门槛。

### H2：独立转向脚轮与球形近似存在影响策略迁移的差异

固定其他条件，对比球形轮、转向+滚动轮、转向锁死、完全固定椅。记录轮角速度、轮地接触点速度、椅架位移与接触力。检查移动是否来自轮滚动、脚轮横滑或非物理碰撞穿透。

固定椅可用于接触与姿态消融；它没有权利通过非零位移重定位验收。禁止通过给椅架加驱动、固定骨盆到座面或每步直接改根位姿来制造物理成功。

### H3：停止后的任务交接需要单独优化和验证

对照：速度跟踪终止即成功，与停止后连续稳定且视野/可达联合通过。随机化桌高、座高、键盘距离和手部载荷。报告“移动成功但工作姿态失败”的比例。后者才对应本项目的实际使用任务。

### H4：滑移约束的收益依赖正则与命令难度

计划 `SY × FS × CC × 4 seeds` 共 32 组。先实现基础环境，确认非零移动后再扩展矩阵；不要直接启动全部算力任务。当前脚本只生成计划，不自动执行 32 组。

FS 作用于足底的有接触滑移，不应和脚轮横滑指标混用。SY 必须依据资产关节顺序、关节轴方向、默认坐姿和动作尺度构造镜像，先验证变换两次恢复原值。CC 必须由独立评估结果提升难度，不能以训练奖励单独驱动。

## 6. 评测与记录

使用 [evaluation.json](../../../configs/chair/evaluation.json) 作为实验设计清单；它不是已实现的自动 evaluator。训练种子与评估种子分开；按方向、速度、椅子型号、地面、桌边约束分层报告。保留所有失败 episode，给出成功分子/分母和置信区间，不能只挑选成功视频。

主指标：位移方向正确且有进度的重定位成功率、速度 RMSE、接触丢失、骨盆偏移、最大倾角、轮子滑移、停止耗时、任务交接成功率、静止局部最优比例。机械功按 `sum(abs(torque * joint_velocity))` 积分；未测电流不能称为真实电耗，位移近零时单位距离能耗应留空。

每次实验保留：配置、代码摘要、物理 worker 提交、模型与椅子哈希、关节映射、种子、奖励分项、完整轨迹、失败码、训练产物哈希、视频路径。当前 runner 输出学习日志；完整物理轨迹与视频需由 worker/evaluator 保存并写入实验目录。

首次允许运行时，顺序是契约测试 → 替身 demo → 物理资产审计 → 单环境回放 → 短训练 → 独立评测 → 消融。没有结果时，论文摘要与项目报告只能写方案，不能填写成功率或训练时长。

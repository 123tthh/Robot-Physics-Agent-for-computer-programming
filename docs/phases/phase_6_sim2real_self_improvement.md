# P6：Sim-to-real、评测与安全自改进

状态：`PLANNED`

## 目标

把已通过仿真门槛的 Skill 逐项迁移到 G1，并允许按键等技能基于失败证据持续改进，但不允许学习系统修改安全规则、验证规则或自身权限。

## 真机开放顺序

```text
硬件身份确认
→ 吊具/台架零命令
→ 单臂与单指
→ 固定键盘单键
→ 双手组合键
→ 固定坐姿短文本
→ 坐下与椅子调整
→ 低速导航
→ 端到端任务
```

不要一次性开放全身、双手、导航和代码任务。

## 任务

### P6-T01：硬件身份与 HIL 门槛

状态：`PLANNED`

产物：

- G1 实际 `mode_machine`、腕部和关节顺序；
- 灵巧手法兰、电源、通信和急停；
- 仿真/真机一致的策略 Manifest；
- Hardware-in-the-loop 回归台架。

验收：任何身份、关节顺序、频率或归一化不一致都会拒绝使能。

### P6-T02：单 Skill 真机替换

状态：`PLANNED`

产物：

- 按 `calibrate_keyboard`、`press_key`、`press_chord` 等逐项替换模拟实现；
- 同一契约下对比仿真与真机证据；
- 安全停止和恢复演练；
- 每项 Skill 的真机能力等级记录。

验收：真机实现不要求修改高层 Agent 或复制另一套工作流。

### P6-T03：手—键盘自改进

状态：`PLANNED`

允许学习的内容：

- 每个手指—按键的三维落点偏置；
- 按键深度、保持力和释放轨迹；
- 手指分配的成功率/代价模型；
- 受限的腕部或指尖残差策略；
- 不同键盘的标定先验。

禁止学习系统修改：

- 力、速度、碰撞和工作空间硬限制；
- Skill 前置条件和资源锁；
- Verifier 的可信来源和软件测试规则；
- Agent 的工具权限；
- 真机身份与策略兼容校验。

验收：候选策略必须离线回放、仿真回归、阴影运行和小流量真机测试均通过，才能提升为新 Skill 版本；旧版本可回滚。

### P6-T04：端到端 Benchmark 与消融

状态：`PLANNED`

产物：

- 任务集、场景种子和故障注入；
- 无 Verifier、无恢复、无学习残差、单手/双手等消融；
- 成功率、交接失败、误触、恢复代价、人工接管和安全指标；
- 仿真、HIL、真机分层报告。

验收：失败能归因到具体 Skill、状态、证据或交接条件；实验可回放和复现。

## 阶段退出条件

- 端到端任务在真机完成且有完整证据链；
- 无未验证状态推进和低层权限越界；
- 自改进策略在独立测试集上优于基线且不降低安全指标；
- 每个结果明确区分仿真、HIL 与真机。

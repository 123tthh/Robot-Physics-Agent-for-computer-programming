# P5：全局导航与本地语音入口

状态：`PARTIAL`

## 目标

让用户通过电脑或机器人麦克风给出目标，系统把目标转换为受限 SkillGraph，并通过独立导航子系统到达指定工位。

## 导航边界

全局导航推荐实现为独立 L3 复合 Skill：

```text
navigate_to_workstation(workstation_id)
→ 定位
→ 全局路径规划
→ 局部避障与速度命令
→ 到站精对齐
→ Verifier 确认位姿、稳定和坐下入口域
```

导航内部可以有地图服务、规划器和恢复状态机，但高层 Agent 只看到目标、进度、失败码和到达证据。默认不需要另一个能够自由调用机器人低层命令的 LLM Agent。

## 任务

### P5-T01：导航 Skill 与 Adapter 契约

状态：`READY`

产物：

- 工位 ID、目标位姿、容差和最大时长；
- 定位、规划、局部控制和到站状态；
- `{vx, vy, yaw_rate}` 限幅输出；
- 阻塞、定位丢失、无法规划和未稳定失败码。

验收：Agent 无法绕过导航 Skill 直接发送速度或关节命令。

### P5-T02：Isaac 导航场景

状态：`PARTIAL`（P1 静态资产底座已完成；地图、规划和 rollout 未完成）

产物：

- 已有：8×6 m 房间入口、A/B/C 三工位、移动椅、桌面、出生/入口锚点和静态碰撞障碍；
- 固定地图和可复现动态障碍；
- 到站后对椅入口域；
- 路径阻塞和重规划场景。

当前 P1 只验收静态几何、语义 ID、锚点和碰撞体，配置见 [`../../configs/simulation/p1_navigation_room.json`](../../configs/simulation/p1_navigation_room.json)。完整退出验收仍要求 `workstation_reached` 由定位和姿态证据确认，不能由导航控制器单独写入。

### P5-T03：本地麦克风、VAD 和 ASR

状态：`PLANNED`

产物：

- 麦克风设备 Adapter；
- 端点检测、转写和置信度；
- 文本替身、预录音频和实时输入三种模式；
- 噪声、电机声、取消和紧急词测试。

验收：命令集上的转写、端点延迟和漏检可量化；急停有独立兜底通道。

### P5-T04：轻量本地工具规划器

状态：`PLANNED`

产物：

- 锁定 ASR/LLM 模型、量化、许可证和推理版本；
- 结构化任务和 L2/L3 工具调用；
- 白名单、调用预算和越权测试；
- 机器人边缘和工作站两档基准。

验收：工具选择、参数准确率和越权率在项目命令集上通过门槛；模型不参与高频控制。

## 阶段退出条件

- “去工位 A”能触发导航并得到独立到达证据；
- “用 Codex 写 hello world”能生成合法 SkillGraph；
- 否定、取消、恢复和紧急指令有明确语义；
- ASR/LLM 失败不会导致机器人继续执行不确定动作。

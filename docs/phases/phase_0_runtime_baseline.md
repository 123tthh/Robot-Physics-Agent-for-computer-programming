# P0：Runtime、契约与证据基线

状态：`DONE`，后续阶段持续回归。P0-T01/P0-T02 已于 2026-09-04 完成纯 Python 验收。

## 目标

建立不依赖机器人和大模型的 Agent–Skill 运行时，使所有后续物理能力都能以相同契约执行、验证、记录和恢复。

## 已有能力

- 版本化 Skill 契约与 Registry；
- 前置条件、资源锁、超时和异常隔离；
- 独立 Verifier 才能推进状态；
- 物理、GUI、软件和系统证据；
- SQLite 事件账本、检查点和恢复记忆；
- 故障注入、恢复和基准场景；
- G1 身份与策略兼容性校验；
- 本地语音规划器的工具白名单边界。

## 维护任务

### P0-T01：状态有效期和失效传播

状态：`DONE`

目标：为键盘标定、工作姿态、屏幕焦点等易失状态增加 TTL/失效条件。

产物：

- 状态时间戳和有效期模型；
- 依赖状态失效传播；
- 时钟可注入，测试不依赖真实等待；
- 正常、过期和恢复测试。

验收：过期的 `keyboard_calibrated` 或 `work_pose_ready` 能阻止按键控制器启动。

### P0-T02：跨进程调用与取消协议

状态：`DONE`

目标：为 Isaac、桌面和模型 worker 定义可替换的请求、进度、取消和结果协议。

不在范围：实现 ROS 2 或 DDS 的全部传输。

验收：使用本地替身进程证明超时、取消、重复消息和 worker 退出不会错误推进状态。

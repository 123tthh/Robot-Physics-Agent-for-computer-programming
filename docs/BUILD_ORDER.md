# 构建顺序与验收门槛

本文件描述技术依赖，不包含时间安排。

## 1. 工程骨架

- Skill 契约、Registry、Runtime；
- 前置条件、资源锁和结果模型；
- SQLite 事件账本；
- Verifier 与 Recovery 接口；
- 模拟端到端回归测试。

门槛：每次调用均可追踪，未满足前置条件时控制器不会启动，测试失败能够触发恢复 Skill 并重试。

## 2. 固定坐姿键盘 MVP

- 相机标定、键盘检测和键位坐标；
- 单键与 `Ctrl+Alt+T`；
- 屏幕检测、OCR、终端可见与焦点验证；
- 误触、漏触和未聚焦失败码。

门槛：系统能区分“完成按压轨迹”和“终端真正可输入”。

## 3. 真实数字 Agent 闭环

- Codex 隔离工作区；
- 任务提交、观察、错误反馈；
- 独立测试执行器；
- 已验证检查点与中断恢复。

门槛：完成生成—测试失败—反馈—修复—测试通过，且 Codex 的文字声明不能绕过验证。

## 4. 学习式按键 Skill

- 几何控制基线；
- 视觉伺服；
- 小范围残差策略；
- 键盘位姿扰动和自动事件标签。

门槛：在键盘平移、旋转和标定噪声下显著优于纯几何基线。

## 5. 全身坐下与工作姿态

- 运动采集和重定向；
- Isaac Lab 多接触运动模仿；
- 椅子/桌面随机化；
- 任务约束残差策略；
- 坐稳、屏幕可见和双手可达联合 Verifier。

门槛：`sit_and_prepare_for_typing` 同时满足稳定性、视野和可达性，而非仅检测臀部接触。

## 6. 端到端与论文评测

- 导航、对椅、坐下、操作、代码任务集成；
- 物理、GUI、软件故障注入；
- 状态机、普通 Agent+Skill、Verifier、恢复记忆等消融；
- 自动汇总成功率、交接失败、恢复率和人工干预。

门槛：端到端失败能够定位到具体 Skill、状态或交接条件，实验可批量回放和复现。

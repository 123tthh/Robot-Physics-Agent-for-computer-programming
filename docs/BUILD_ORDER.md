# 构建顺序与验收门槛

> 面向 Codex 的任务编号、范围和逐阶段退出条件见 [`phases/README.md`](phases/README.md) 与 [`CODEX_WORKPLAN.md`](CODEX_WORKPLAN.md)。本文保留为高层依赖摘要。

本文件描述技术依赖，不包含时间安排。

状态说明：P0 与 P1 资产/底座已完成，P2 保持 `PARTIAL`。P1 在本机 Isaac Sim 5.1 / Isaac Lab 2.3.2 中加载固定基座 G1 mode 15 / 5010、双 Dex3、五脚轮办公椅、8×6 m 四墙房间、三工位与 12 个导航/工作锚点、74 键带标识键盘、PhysX 接触、三路 RTX 相机及 PTY；P2 已有模块化 ActionGraph 和自动事件诊断，但 GUI 尚未确认可见实体触键。真实导航 rollout、坐下、载人椅子动力学、camera-only 视觉验证、策略训练与真机均不能由当前报告替代。

## 1. 工程骨架

- Skill 契约、Registry、Runtime；
- 前置条件、资源锁和结果模型；
- SQLite 事件账本；
- Verifier 与 Recovery 接口；
- 模拟端到端回归测试。

门槛：每次调用均可追踪，未满足前置条件时控制器不会启动，测试失败能够触发恢复 Skill 并重试。

## 2. 固定坐姿键盘 MVP

- 相机标定、键盘检测和键位坐标；
- 单键与 `Ctrl+Alt+T`；
- 屏幕检测、OCR、终端可见与焦点验证；
- 误触、漏触和未聚焦失败码。

门槛：系统能区分“完成按压轨迹”和“终端真正可输入”。

## 3. 真实数字 Agent 闭环

- Codex 隔离工作区；
- 任务提交、观察、错误反馈；
- 独立测试执行器；
- 已验证检查点与中断恢复。

门槛：完成生成—测试失败—反馈—修复—测试通过，且 Codex 的文字声明不能绕过验证。

## 4. 学习式按键 Skill

- 几何控制基线；
- 视觉伺服；
- 小范围残差策略；
- 键盘位姿扰动和自动事件标签。

门槛：在键盘平移、旋转和标定噪声下显著优于纯几何基线。

## 5. 全身坐下与工作姿态

- 运动采集和重定向；
- Isaac Lab 多接触运动模仿；
- 椅子/桌面随机化；
- 任务约束残差策略；
- 坐稳、屏幕可见和双手可达联合 Verifier。

门槛：`sit_and_prepare_for_typing` 同时满足稳定性、视野和可达性，而非仅检测臀部接触。

## 6. 无动力轮椅坐姿移动

- `SeatedLocomotionPolicyAdapter` 对接 mjlab/ONNX；
- actor 仅使用真机可得的 96 维本体观测与速度命令；
- critic-only 的座椅/接触信息不得进入部署输入；
- 分别评测前、后、侧向和转向，覆盖座面接触丢失、倾角超限和静止局部最优；
- 每次移动结束必须重过工作姿态守卫，才能开始键盘标定。

门槛：超时成功率不能代替移动成功；必须同时满足非零进度、速度 RMSE、
骨盆—座椅偏移、接触丢失时长、躯干/座椅倾角与结束后稳定阈值。

## 7. 端到端与论文评测

- 导航、对椅、坐下、操作、代码任务集成；
- 物理、GUI、软件故障注入；
- 状态机、普通 Agent+Skill、Verifier、恢复记忆等消融；
- 自动汇总成功率、交接失败、恢复率和人工干预。

门槛：端到端失败能够定位到具体 Skill、状态或交接条件，实验可批量回放和复现。

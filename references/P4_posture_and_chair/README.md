对应规划：[`docs/phases/phase_4_posture_and_chair.md`](../../docs/phases/phase_4_posture_and_chair.md)

## 收录范围

- 坐下/站起、运动重定向和全身模仿；
- 多接触稳定、屏幕可见和双手可达；
- 无动力万向轮椅坐姿移动；
- 移动结束后的工作姿态再验证与局部恢复。
